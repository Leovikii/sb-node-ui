# v3.0 重构历史摘要

`3.0.0` 于 2026-07-17 完成 Phase 0–9。完整逐任务记录已从工作树删除，可通过 Git 历史查阅；本文件只保留理解当前架构所需的结论。

## 最终架构

- R2 Standard 是唯一持久化，workspace 使用 immutable revision、head pointer 和 ETag CAS。
- 会话使用签名 HttpOnly Cookie；私有订阅使用确定性短 HMAC Token；无 KV/D1。
- Workers Cache API 只保存可丢弃、revision-aware 响应。
- GitHub private repository 只作用户主动 sync/backup，不参与日常 CRUD。
- SRS 由私有仓库 GitHub Actions 无状态编译，通过短期 ticket 调用 Worker，产物写入 R2。
- Worker 已分为 domain、application、ports、infrastructure 和 HTTP route；浏览器只使用 typed API。

## 产品与数据结论

- 每个部署管理一个 `primary` workspace。
- Profile 使用 workspace 模板、节点集和可选 replacement adapter。
- 通用 patch DSL、外部模板 URL、旧 workspace v1 兼容代码均已删除。
- Ruleset JSON 公开可用，SRS 为可选优化；构建失败保留旧 active SRS。
- GitHub sync 使用 base/local/remote 整体摘要，双方变化时只允许用户明确整侧覆盖。
- 部署采用 fork + Cloudflare Workers Builds；代码 rollback 与 R2 restore 分离。

## 3.0 前端结论

- Vue 3、PrimeVue 4、Pinia、Vue Router、Vue I18n 和 Tailwind 4 完成过一次前端平台重构。
- 3.0 收束了 320 px 响应式、44 px 触控目标、弹窗稳定布局、双语、暗色首帧、Firefox 路由切换和 Ruleset 单链接。
- 这些是 3.1 行为验收基线，不代表 React/Mantine 必须复刻 3.0 视觉。

## 发布状态

- 稳定版本为 `3.0.0`，许可证为 GPL-3.0-only。
- 发布前验证通过 lint、三套 typecheck、unit、integration、28 项 Chromium/Firefox E2E、production build 和 Worker dry-run。
- 独立 Cloudflare 账户 fresh-account、普通用户 Sync fork 和真实 Worker rollback 只在有安全测试目标或真实故障时执行，不通过破坏生产资源模拟。
