# v3.1.0 React + Mantine 前端重构计划

状态：`BETA_CANDIDATE`
当前版本：`3.1.0-beta.2`；正式目标：`3.1.0`
范围：仅替换浏览器前端；Worker、API、shared contracts、R2、SRS、GitHub sync 语义不变。

## 目标

- 删除 Vue、PrimeVue、Pinia、Vue Router、Vue I18n、Tailwind 与 vuedraggable。
- 使用 Mantine 原生组件、主题、动画、Modal、Notification 和表单能力，减少自定义样式。
- 保留当前路由、双语、暗色、移动端、JSON 校验/格式化、Profile 排序、revision conflict 和所有业务能力。
- 最终生产构建只包含 React，不长期保留双框架。

## 非目标

- 不调整 Worker route、R2 object、workspace schema、subscription URL 或 sync 协议。
- 不借机重写领域逻辑、SRS 编译或部署流程。
- 不复刻 3.0 视觉；只保留品牌粉色和必要产品语义。
- 不引入 shadcn、MUI、Tailwind、CSS-in-JS 或动画框架作为第二套 UI 系统。

## 技术栈

- React 19.2、React DOM 19.2、`@vitejs/plugin-react`
- Mantine 9：core、hooks、form、modals、notifications
- React Router、Zustand、i18next/react-i18next
- dnd-kit sortable、Lucide React、Mantine JsonInput、Zod
- CSS Modules 仅处理重复列表、编辑器和拖拽状态

## 切换门槛

- 所有 3.0 关键 E2E 在 React 入口通过，且测试不依赖框架私有 class。
- 320/390/412/768/1440 视口无非业务横向滚动，触控目标至少 44 px。
- 暗色首帧无白闪；Firefox 路由切换小于 130 ms；reduced-motion 生效。
- 重型 feature 保持 lazy；初始 gzip 相对 3.0 增幅不超过 10%，总客户端 JS 增幅不超过 15%，并由构建门禁自动执行。
- `npm run verify`、React 专项 build/E2E、许可证扫描和 `worker:dry-run` 全部通过。
- 依赖树不存在 PrimeVue/PrimeUI、自定义商业许可或许可证密钥机制。

## 回滚

默认入口切换前，删除 `src-react` 和 React build 配置即可回到 3.0 Vue 入口。切换后若发布验证失败，只回滚 Worker code version；R2 revision 和用户数据不回滚、不迁移，因为本计划不改变数据格式。
